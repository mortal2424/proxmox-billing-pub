# Приложение HomeVlad

Один нативный клиент для пользователя и администратора на каждой платформе: SwiftUI для iOS и Kotlin Compose для Android. Встроенного браузера в приложениях нет. Административное меню появляется по роли из БД.

Реализованы вход по email, паролю и CAPTCHA, баланс, список машин и управление питанием с подтверждением, мониторинг инфраструктуры, история платежей, создание обращений и переписка. Администратор может просматривать обращения пользователей и подтверждать или отклонять ожидающие платежи. Для активных и закрытых обращений сервер формирует отдельные списки, до 100 записей в каждом.

Создание машин, VNC-консоль, пополнение баланса и остальные настройки пока доступны на сайте. Наличие нативного приложения не означает, что перенесены все функции панели. Telegram-вход в приложении пока не реализован.

Cookies хранятся в памяти отдельной HTTP-сессии приложения; пароли не сохраняются. При выходе серверная сессия закрывается, локальные cookies удаляются. Для входа после перезапуска может потребоваться повторная авторизация.

## Сервер

Нужны маршруты `api/mobile_auth.php`, `api/mobile_dashboard.php` и `api/mobile_resources.php` из пакета обновления. Запросы изменения данных требуют CSRF-токен. API повторно читает активность пользователя и роль из БД; пользователь получает только свои машины, платежи и обращения. Учётные данные узлов не включаются в ответ. HTTPS-соединение с Proxmox проверяет доверенный CA или заранее проверенный отпечаток сертификата узла.

Сначала установите серверный пакет через систему обновлений панели, затем распространяйте приложение. До установки API нативный вход не работает.

## iPhone

Откройте `ios/HomeVlad.xcodeproj` в Xcode, выберите схему `HomeVlad`.

- Debug обращается к `https://dev.homevlad.ru`, идентификатор `ru.homevlad.cloud.dev`.
- Release обращается к `https://homevlad.ru`, идентификатор `ru.homevlad.cloud`.
- Минимальная версия iOS — 17.
- Для установки на физическое устройство выберите свою команду в Signing & Capabilities.
- Для симулятора подпись не требуется.

Если `xcode-select` указывает на Command Line Tools, задайте путь для команды сборки.

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project mobile/ios/HomeVlad.xcodeproj -scheme HomeVlad \
  -sdk iphonesimulator -configuration Debug \
  -derivedDataPath /tmp/homevlad-ios-build CODE_SIGNING_ALLOWED=NO build
```

## Android

Откройте `android` в Android Studio. Нужны JDK 17, Android SDK 35 и Build Tools. Путь к SDK задаётся через `ANDROID_HOME` или локальный `local.properties`.

- Debug использует dev.homevlad.ru и идентификатор `ru.homevlad.cloud.dev`.
- Release использует homevlad.ru и идентификатор `ru.homevlad.cloud`.
- Минимальная версия Android — 8.0, API 26.
- Для распространения Release настройте собственную подпись. Ключи подписи хранятся вне репозитория.

```sh
cd mobile/android
./gradlew :app:assembleDebug
```

APK находится в `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка перед распространением

На dev-сайте проверьте вход, CAPTCHA, обычного пользователя и администратора, список машин, просмотр машин, подтверждения команд питания, платежи, обращения и выход. Проверьте отказ доступа после отзыва роли, истечение сессии и работу при недоступной сети. Сборка исходников сама по себе не подтверждает эти сценарии.
