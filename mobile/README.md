# Приложение HomeVlad

Один нативный клиент для пользователя и администратора на каждой платформе: SwiftUI для iOS и Kotlin Compose для Android. Встроенного браузера в приложениях нет. На обеих платформах переключатель в шапке меняет интерфейс и навигацию целиком. Он доступен по роли из базы.

Реализованы вход по email, паролю и CAPTCHA, баланс, список машин и управление питанием с подтверждением, мониторинг инфраструктуры, история платежей, создание обращений и переписка. Администратору доступны сводка системы, список пользователей, обращения и подтверждение или отклонение ожидающих платежей. Мобильный мониторинг показывает RX/TX и доступность интернета из контрольных ВМ. Для активных и закрытых обращений сервер формирует отдельные списки, до 100 записей в каждом.

В приложении можно заказать ВМ из cloud-образа или LXC из шаблона с выбором зоны, пулов и тарифа. Карточка гостя содержит графики CPU, памяти, диска и сети за час, день, неделю, месяц или год. В iOS и Android консоль запускается из карточки работающей ВМ или LXC через сессию HomeVlad. Нужен сервер v2.5.1-beta8.39 или новее. Для LXC требуется API-токен на ноде. Если экран LXC пуст, нажмите Enter, чтобы вызвать приглашение входа. Установка с ISO, индивидуальные ресурсы и пополнение доступны на сайте. Наличие нативного приложения не означает, что перенесены все функции панели. Telegram-вход в приложении пока не реализован.

Cookies хранятся в памяти отдельной HTTP-сессии. После входа с паролем и CAPTCHA можно включить Face ID на iPhone или биометрический вход по отпечатку на Android в разделе безопасности обзора. После перезапуска нажмите кнопку биометрического входа. iOS защищает токен в Keychain с привязкой к текущей биометрии, Android шифрует его через Keystore с подтверждением BiometricPrompt. Пароль сайта не сохраняется. Токен действует до 30 дней. Смена пароля инвалидирует токен, выход удаляет его локально и отзывает токен текущей сессии.

## Сервер

Серверный пакет v2.5.1-beta8.40 добавляет `api/mobile_admin.php`. В режиме администратора доступны ВМ и LXC всех пользователей. Поиск работает по имени гостя, VMID, имени владельца и email. Из карточки доступны графики, запуск, выключение, перезагрузка, остановка и VNC.

В разделе «Ноды и зоны» администратор может добавлять зоны, менять лимит гостей, порог нагрузки и режим обслуживания. Для нод доступны добавление по API-токену, редактирование, проверка API и импорт участников кластера. Отключение новых заказов оставляет доступ к работающим гостям. При наличии связанных машин переадресация ноды или её перенос между зонами блокируются. Поле секрета при редактировании пустое. Укажите новый секрет при смене адреса, порта или ID токена.

Нужны маршруты `api/mobile_auth.php`, `api/mobile_dashboard.php`, `api/mobile_resources.php`, `api/mobile_order.php` и `api/mobile_console.php` из пакета обновления. Запросы изменения данных требуют CSRF-токен. API повторно читает активность пользователя и роль из БД; пользователь получает только свои машины, платежи и обращения. Учётные данные узлов не включаются в ответ. HTTPS-соединение с Proxmox проверяет доверенный CA или заранее проверенный отпечаток сертификата узла.

Сначала установите серверный пакет через систему обновлений панели и примените схему токенов на существующей базе. Новый Docker-образ применяет схему при запуске.

```sh
php cronjobs/create_mobile_device_tokens.php
# Для существующей Docker-установки с обновлёнными файлами:
docker compose exec --user www-data apache php cronjobs/create_mobile_device_tokens.php
```

После этого распространяйте приложения. До миграции вход с паролем продолжает работать, включение и использование биометрического входа требуют новой таблицы.

## iPhone

Откройте `ios/HomeVlad.xcodeproj` в Xcode, выберите схему `HomeVlad`.

- Debug обращается к `https://dev.homevlad.ru`, идентификатор `ru.homevlad.cloud.dev`.
- Release обращается к `https://homevlad.ru`, идентификатор `ru.homevlad.cloud`.
- Минимальная версия iOS — 17.
- Для установки на физическое устройство выберите свою команду в Signing & Capabilities.
- Для симулятора подпись не требуется.

Если `xcode-select` указывает на Command Line Tools, задайте путь для команды сборки.

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project mobile/ios/HomeVlad.xcodeproj -scheme HomeVlad \
  -sdk iphonesimulator -configuration Debug \
  -derivedDataPath /tmp/homevlad-ios-build CODE_SIGNING_ALLOWED=NO build
```

## Android

Откройте `android` в Android Studio. Нужны JDK 17, Android SDK 35 и Build Tools. Путь к SDK задаётся через `ANDROID_HOME` или локальный `local.properties`.

- Debug использует dev.homevlad.ru и идентификатор `ru.homevlad.cloud.dev`.
- Release использует homevlad.ru и идентификатор `ru.homevlad.cloud`.
- Минимальная версия Android — 8.0, API 26.
- Для распространения Release настройте собственную подпись. Ключи подписи хранятся вне репозитория.

```sh
cd mobile/android
./gradlew :app:assembleDebug
```

APK находится в `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка перед распространением

На dev-сайте проверьте вход, CAPTCHA, обычного пользователя и администратора, список машин, просмотр машин, подтверждения команд питания, платежи, обращения и выход. На физических устройствах проверьте включение Face ID или отпечатка, холодный старт, отмену системного запроса и добавление новой биометрии. Проверьте отказ доступа после отзыва роли, истечение токена, выход, смену пароля и работу при недоступной сети. Сборка исходников сама по себе не подтверждает эти сценарии.
