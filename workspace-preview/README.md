# Предпросмотр кабинета HomeVlad

Откройте `/workspace-preview/` на `dev.homevlad.ru`. В отдельной директории находятся интерфейс и API чтения. Для просмотра используется отдельная пара логин и пароль. Она даёт доступ к машинам одного заданного активного аккаунта HomeVlad. Кнопка в конфигураторе проверяет поля локально, без создания заказа. Доступность образов на конкретной ноде и итоговые условия заказа проверяет рабочая панель.

## Подключение к текущим данным

1. Разместите эту директорию и `includes/cloud_images.php` из того же коммита в веб-корне dev. Веб-сервер должен выполнять PHP по HTTPS и передавать заголовок авторизации в PHP.
2. Создайте отдельного локального пользователя MySQL с правом `SELECT` на используемые столбцы таблиц `users`, `vms`, `vms_admin`, `proxmox_nodes`, `proxmox_clusters`, `node_placement_pools`, `tariffs`, `vm_metrics` и `lxc_metrics`. Набор столбцов указан в запросах `data.php`. У пользователя предпросмотра должны быть только эти права. Секреты Proxmox, пароли клиентов и платежи предпросмотру не нужны.
3. Создайте конфигурацию вне веб-корня. Путь по умолчанию для MyVesta — `~/.config/homevlad-workspace.php`. Другой путь можно задать через `HOMEVLAD_WORKSPACE_CONFIG`. Сделайте файл доступным только владельцу и PHP-процессу dev. Используйте отдельный случайный пароль предпросмотра и храните в файле его хеш, полученный через PHP `password_hash`.

```php
<?php
return [
    'login' => 'preview',
    'password_hash' => '<результат password_hash()>',
    'account_id' => 0, // Замените на ID своего аккаунта HomeVlad.
    'account_label' => 'Мой кабинет',
    'dsn' => 'mysql:host=localhost;dbname=<имя базы>;charset=utf8mb4',
    'db_user' => '<пользователь SELECT>',
    'db_password' => '<пароль пользователя SELECT>',
];
```

До настройки подключения сервер возвращает ошибку и не раскрывает данные. Статусы и IP читаются из базы панели. Вкладка метрик показывает до 120 последних сохранённых измерений. Если VMID неоднозначен, история скрывается. Тестовые данные можно подставить отдельно на локальном HTTP-сервере вместо `data.php`.
